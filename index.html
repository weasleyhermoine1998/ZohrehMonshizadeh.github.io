Numerical Interpolation Methods

  • FieldNumerical Analysis
  • EnvironmentMATLAB 2015

Implementation and Comparison of Numerical Interpolation Methods in MATLAB

This project focuses on the implementation and comparison of numerical interpolation methods using MATLAB. Three interpolation techniques were implemented and studied:

Interpolation Methods
  • Cubic Hermite Interpolation: A method that uses both function values and first-derivative values at interpolation nodes to construct a piecewise cubic approximation.
  • Natural Cubic Spline Interpolation: A piecewise cubic interpolation method with zero second derivatives at both endpoints.
  • Clamped Cubic Spline Interpolation: A cubic spline method that incorporates specified first-derivative values at the endpoints.
Implementation Features
  • Defining different mathematical functions, including polynomial and trigonometric functions.
  • Selecting arbitrary interpolation nodes.
  • Using analytical or numerical derivatives.
  • Evaluating interpolating functions at arbitrary points.
  • Computing and analyzing interpolation errors.
  • Plotting the original function and its interpolants.
  • Graphically comparing the approximation errors of the implemented methods.

Bessel Functions and Their Applications

This independent research project focuses on the mathematical study of Bessel functions and their role in solving differential equations.

The project covers the power series method for solving differential equations, the Gamma function, and the derivation and solutions of Bessel's differential equation. It also examines Bessel functions of different orders, Hankel functions, modified Bessel equations, and differential equations that can be transformed into Bessel's equation.

Furthermore, the study explores important properties of Bessel functions and introduces Maple as a computational tool for mathematical calculations and the investigation of differential equations.

Main Topics
  • Power Series Methods for Differential Equations
  • Gamma Function
  • Bessel's Differential Equation
  • Bessel Functions of Different Orders
  • Hankel Functions
  • Modified Bessel Equations
  • Differential Equations Reducible to Bessel's Equation
  • Properties and Zeros of Bessel Functions
  • Computational Applications Using Maple
